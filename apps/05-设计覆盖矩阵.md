# 设计覆盖矩阵

本文件把 `.design` 的每一个实体、设计决策、要求与接缝分配到唯一的首次交付 Stage，使 `AGENTS.md` 规则 3 的追溯纪律与 `03-验证发布与验收门禁.md` 的追溯检查从第一天起可执行。

分配表达的是“该对象首次成为可验证实现约束的 Stage”，不是它唯一被触碰的 Stage；后续 Stage 仍可扩展同一对象。任何进入实现的能力必须能在本文件找到归属，找不到即说明设计或路线缺一环，按 `04-上游适配与升级.md` 的先改设计流程处理。

本文件是派生视图，不引入新语义。与 `.design` 冲突时以 `.design` 为准。

## 1. 覆盖自检

每次修改 `.design` 或本文件后必须重跑三项计数。计数只统计对应小节**表格行内**的标识符，不统计表下的说明段落；任一不等即为缺口：

```text
.design/03 中形如 `实体名(` 的声明数        == §2 各表格行内出现的实体名去重数
.design/02 中 DD-* 定义行数                 == §3 表格行数
.design/02 中 SS-* 定义行数                 == §4 各表格行内出现的接缝去重数
```

当前基线：实体 82、`DD-*` 75、`SS-*` 23、`V-REQ-*` 21、`V-SCN-*` 65。`V-SCN-*` 的 Stage 映射在 `02-纵向交付路线.md` 各 Stage 的验收映射中维护，本文件不重复。
