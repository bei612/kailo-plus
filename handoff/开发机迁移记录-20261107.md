## 4A. 原待办（已完成）
1. **DNS**：`game2.lichking.online` A 记录指向 `199.115.231.214`。
2. **证书**：DNS 生效后，在新机上签发并安装证书：
   ```bash
   /root/.acme.sh/acme.sh --issue --standalone -d game2.lichking.online --keylength ec-256
   /root/.acme.sh/acme.sh --install-cert -d game2.lichking.online --ecc \
     --fullchain-file /root/cert/game2.lichking.online/fullchain.pem \
     --key-file /root/cert/game2.lichking.online/privkey.pem \
     --reloadcmd "systemctl restart x-ui"
   ```

   然后在 x-ui 设置中把 `webCertFile`、`webKeyFile`、`subCertFile`、`subKeyFile` 改为 game2 路径，并重启 x-ui。在此之前，面板暂用旧的 game 证书。

## 5. 迁移中的一次失误
同步 `/root` 时，旧机的 `/root/.ssh/authorized_keys` 覆盖了新机上原有的那份，开发机密钥因此一度失去访问权限，后由用户在新机上补加恢复。以后同步 `/root` 一律排除 `.ssh/authorized_keys`。
